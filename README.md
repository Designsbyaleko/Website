# Alexander Fitzsimons Portfolio

A public portfolio site that doubles as a resume, CV, and project showcase. It highlights my design projects, writing reflections, and professional skills.

## Features

- **Responsive layout**: Adapts to phones, tablets, and desktops  
- **Sticky header**: Always-visible navigation  
- **Hero sections**: Custom gradients and clipped images  
- **Work pages**: Project cards with images, purpose, outcomes, and tools used  
- **Skills & Experience**: Interactive skill cards and software list  
- **Process & Writing**: Five writing sections with alternating backgrounds  
- **Contact form**: Front-end validation and math check to prevent spam  
- **Accessible links**: Skip link, ARIA labels, and smooth scrolling  

## Pages

- **Home**: Hero, about, skills, and contact  
- **Work**: Light Rail Safety Campaign and Golf Adventure Park identity  
- **Skills & Experience**: Core skills and project highlight  
- **Process & Writing**: Reflections and literature review  
- **Contact**: Email form with simple JavaScript validation  

## Tech Stack

- HTML5 & CSS3 (Flexbox, Grid, clip-path)  
- JavaScript (form validation)  
- Google Fonts (Montserrat, Open Sans)
